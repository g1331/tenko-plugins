# tenko-plugin-tarot

[Tenko](https://github.com/g1331/tenko) 的塔罗牌插件，重做自旧版 xiaomai-bot 的 `tarot`。每天一张今日塔罗，
想问点什么就用三张牌阵或凯尔特十字，牌面是 B 站幻星集的完整 78 张。

```text
群友：/今日塔罗
Tenko：你今天的塔罗牌是【星星】（正位）[图片]
       大阿卡那 XVII · The Star
       希望、前途光明、曙光出现
群友：/占卜 这周的面试
Tenko：[过去、现在、未来三张牌排成的图]
群友：/占卜 那下周呢
Tenko：三张牌阵每 60 分钟只能占一次，再等 52 分钟吧。
       上次「这周的面试」：过去 星星（正位）、现在 权杖三（逆位）、未来 圣杯王后（正位）
```

## 命令

| 命令 | 说明 |
| --- | --- |
| `/今日塔罗` | 从 22 张大阿卡那里抽一张今天的牌，当天再抽还是这张 |
| `/塔罗牌 [牌名]` | 查一张牌的牌面和正逆位牌义，例如 `/塔罗牌 宝剑三`、`/塔罗牌 the star`；不带牌名等于 `/今日塔罗` |
| `/占卜 [问题]` | 三张牌阵：78 张里抽过去、现在、未来三张，排成一张图 |
| `/凯尔特十字 [问题]` | 78 张里抽 10 张，按凯尔特十字布局排成一张图，每张牌标出位置、正逆位和关键词 |
| `/塔罗记录` | 自己最近 5 次占卜的结果 |
| `/塔罗知识` | 随机一条塔罗冷知识 |

群聊、私聊都能用。插件在新群默认开启，群管理员可以用 `/关闭 塔罗牌` 关掉。

## 规则

- 记录按人，不分群：在哪个群抽，今天都是同一张牌。日期按服务器时间，零点重置。
- 今日塔罗只用大阿卡那；三张牌阵和凯尔特十字用全部 78 张。每张牌正位、逆位各一半概率，逆位的牌面倒过来显示。
- 三张牌阵两次之间至少隔 60 分钟，从上次占卜起算；没到时间会告诉你还要等多久，并附上上次的结果。
- 凯尔特十字每人每天一次，当天再占会重发今天那一组。
- 元旦、情人节、愚人节、万圣节、平安夜、圣诞节当天，结果后面会附一句应景的话，不影响抽牌。
- 问题最多记 60 个字。所有占卜都存在插件自己的数据库里，`/占卜` 计入限流的权重是 2，`/凯尔特十字` 是 3。

凯尔特十字的十个位置：

```text
          [5 目标]                    [10 结果]
[4 过去]  [1 现状 ✚ 2 阻碍]  [6 近未来]   [9 希望与恐惧]
          [3 根基]                    [8 环境]
                                      [7 自我]
```

## 安装

在 WebUI 的插件市场安装，或由 Master 在聊天里 `/安装插件 tarot`。装好后默认不启用，`/启用插件 tarot` 即可加载。

## 配置

`config/tenko.toml` 的 `[plugin_config.tarot]`，也可以在 WebUI 的插件配置里修改：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `three_card_minutes` | `60` | 三张牌阵两次之间至少隔多少分钟；`0` 表示不限 |
| `celtic_cross_daily` | `true` | 凯尔特十字每人每天一次；关掉后不限次数 |

## 牌面与牌义

牌面是 bilibili 幻星集塔罗牌，取自 [MinatoAquaCrews/nonebot_plugin_tarot](https://github.com/MinatoAquaCrews/nonebot_plugin_tarot)
的 `resource/BilibiliTarot`，从 948×1894 的 PNG 缩成 480 宽、质量 85 的 JPEG。牌面版权归原作者所有。

牌义改自同一项目的 `tarot.json`（MIT 许可证）：牌名统一成“宝剑王牌、宝剑二……宝剑王后”，修正了英文名和错字，
重写了宝剑六的正逆位，换掉了几处不适合在群里发的措辞。

## 图标

`icon.png` 以 [Phosphor Icons](https://phosphoricons.com) 的 `cards`（fill）转成竖放为底，在前面那张牌上镂空 `star-four`（fill）的四芒星，Phosphor Icons 以 MIT 许可证发布。
