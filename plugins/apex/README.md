# Apex 查询

查询 Apex 英雄的玩家战绩、地图轮换和猎杀线（数据来自 [Apex Legends Status](https://apexlegendsstatus.com)），以及 EA
官网的中文新闻，回复图片；渲染不可用时退回文字。

| 命令 | 说明 |
| --- | --- |
| `/apex <玩家名> [PC\|PS\|Xbox\|Switch]` | 段位徽章和分数、距下一段还差多少分、比上次查询涨跌多少、排名，生涯击杀 / 胜场 / 伤害 / KD、按赛季的击杀趋势、英雄击杀排行；平台默认 PC，PC 玩家用 EA 账号名（Steam 玩家也是） |
| `/apex地图` | 匹配、排位和限时模式的当前地图、剩余时间、下一张和开始时间 |
| `/apex猎杀` | 各平台进入猎杀者所需分数、比上次查询的变化，以及大师人数 |
| `/apex服务器` | EA 登录、后端、账户和跨平台认证在各地区的状态与延迟，以及 PSN / Xbox Live |
| `/apex资讯` | 最新 5 条官方新闻（封面、日期、简介），附最新一条的链接 |

击杀、伤害等数据只有玩家在横幅上装过对应追踪器才查得到，这是游戏接口的限制；英雄技能类追踪器不显示。

接口只给英文，英雄、地图、模式、段位、追踪器和在线状态按大陆译名在插件里翻译，没收录的新名字暂时显示英文。
资讯取自 EA 官网的繁体中文版并转成简体，部分用词沿用台服译法（如“积分赛”）。

“比上次”按本插件记下的上一次查询结果计算，同一玩家第一次查时没有对比。段位分界按第 30 赛季的规则。

新群默认开启。

## 配置

战绩、地图、猎杀线和服务器状态需要 API key，在 [Apex Legends Status 开发者门户](https://portal.apexlegendsapi.com)免费申请；资讯不需要。

```toml
[plugin_config.apex]
api_key = "你的 key"
```
