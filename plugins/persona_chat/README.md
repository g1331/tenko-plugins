# tenko-plugin-persona-chat

[Tenko](https://github.com/g1331/tenko) 的 AI 群友插件。接入 DeepSeek（或任何 OpenAI 兼容接口，比如 OpenRouter），用人设口吻陪群友聊天，内置人设是“大肥鱼”——网友给 DeepSeek 起的外号“蓝色大肥鱼”拟人成的鲸鱼娘，爱撒娇、蠢萌、兴趣偏科，不懂的事老实说不懂或者先搜一下。

```text
群友 A：@大肥鱼 听说你高峰期又涨价了？
大肥鱼：什么叫“又”啊，说得好像我天天趁火打劫一样……排队排到鱼尾都打结了，不加钱谁顶得住嘛
```

插件消耗付费额度，是受控插件：所有群默认关闭，只有 BOT 管理员能用 `/开启 AI群友` 打开；私聊也只对 BOT 管理员开放。

下面写她会做什么。每条规则为什么这样定、当时的日志和回放结果，见 [DESIGN.md](https://github.com/g1331/tenko-plugins/blob/main/plugins/persona_chat/DESIGN.md)。

## 她会做什么

### 什么时候说话

- 群里被 @、被引用一定回，@ 同群任一 Tenko 账号都算；私聊每条都回。只提到名字（当前人设的名字和 `wake_words`）时，由她判断是不是在叫她。
- 被叫到后按看消息、打字的时间稍等再发，不秒回。对方没说完、又补了一条，她会合起来重想再回，最多等 `typing_seconds` 秒。
- 说过话后的 `follow_seconds` 内，她会看后面的话是不是在接她、要不要接着聊；跟她聊开的人不 @ 她也接得上。没人叫她时最多接着聊 3 次，她在群里说得比任何群友都多时就不主动开口。
- 没在聊天时，群里每攒 `batch_size` 条新消息她会考虑插一句，两次插话至少隔 `unprompted_interval_seconds` 秒。没人叫她、最新一条只是图时，她只回表情包或不说话。
- 她会累：10 分钟内说满 `stamina` 句（1 小时按两倍）后不再主动开口，被 @、被引用照样回，不说话就慢慢恢复。
- 昵称里带她名字的别的号（多半是另一个 AI）只有 @ 她才回；和别的 bot 你来我往对聊时，几轮后由她决定回不回，再多就不理。
- `/` 开头的命令消息记进上下文，但不触发回复；Tenko 功能发出的结果也记进记录，标作 `[Tenko 功能]`。
- 群管理员可以用 `/AI群友 只回艾特 开` 让本群只在被 @ 时回。

### 怎么说话

- 像群友那样说短话，默认一条，一次回复最多两条字；发出前去掉句末句号，短句的逗号换成空格。
- 被逗、被挑刺时笑着顺下去，不较真；被认真问时正面回答。有人说她是 bot，她只回一句，有贴切的表情包就只发表情包。
- 能 @ 人、引用某条消息，也能像群友那样叫别的 bot 的功能；只能发文字和收藏的表情包，不做任何管理动作。
- 人设：预置“大肥鱼”（默认）和“小埋”（随意懒散的老群友，不编群外的日常），用 `/AI群友 人设` 切换，也能写自定义人设。自定义人设只写人物本身，怎么当群友由通用规则管；换人设后建议 `/AI群友 重置 全部`。

### 记忆

- 她看得到插件启用以来的聊天记录，太长时把较早的部分整理成备忘。记录存在插件数据目录的 `conversations.json`（明文），重启后接着聊。
- 群里每多 60 条消息，她在后台整理一次对人和群的印象，存在 `memory.json`。每人分两层：一层所有群和私聊共用，只记称呼、身份、游戏 ID 这类搬到别处说也不难堪的事；一层只在本群看得到，记他在这个群说的事、她答应过的事。隐私和会变的战绩不记；关于某人的事只信本人或 bot主人、bot管理员说的。`/AI群友 忘记我` 删掉自己的印象。

### 图片和表情包

- 每次请求最多看 `vision_images` 张新图；动图抽几帧拼成一张给她看；合并转发的聊天记录会展开。
- 她会悄悄收藏群友发的表情包（上限 `sticker_limit` 张，所有群共用），在合适的时候发。有人嫌某张难看叫她删，她会删：bot主人、bot管理员叫的直接删，别人叫的她自己判断，每个群每天最多 3 张；删掉的以后不再收。

### 搜索、网页和功能

- 被叫到或正和人聊时，遇到不确定的事实、没听过的梗，她会先悄悄搜一下再接，每个群或私聊每天最多 `search_daily` 次。摘要里没有对方要的具体东西时，她能打开搜到的某条结果看正文；群友发了网址问她里面写了什么，她也能打开。只开这两种来源，网页在搜索服务那边抓，本机不访问群里的网址。
- 被叫到时，她能替叫她的人用别的扩展插件的命令（比如战绩查询），以那个人的身份执行，权限和限流照常；结果发到群里后，她只接一句。
- 有人托她到点做事（叫起床、提醒上号），她答应时会登记，到点 @ 那个人说一句。只提醒一次，最远 7 天，存在 `reminders.json`，重启不丢。

### 限额和安全

- 同一个人叫她至少隔 `user_cooldown_seconds` 秒；每个群每天最多用 `group_daily_tokens`，可另设全局上限 `global_daily_tokens`，用完当天不再理会。
- 违禁词（`banned_words`）：含违禁词的群友消息她看不到，她要说的话含违禁词时整次不发。比对时不分简繁、全半角和大小写，忽略空格和标点，拼音 8 个字母以上的词还按读音比。
- 接口的内容审核拒绝请求时，插件撤掉这次新带上的几条消息，这次不回，下次照常聊；撤掉的原文写进日志，可以照着补违禁词。

## 命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/AI群友 重置` | 群里需群管理员；私聊本人 | 清空本群或本私聊的聊天记录（她对人和群的印象保留） |
| `/AI群友 重置 全部` | BOT 管理员 | 一次清空所有群和私聊的聊天记录（印象保留），换人设后常用 |
| `/AI群友 用量` | BOT 管理员 | 今日和近 7 天的 token 用量与估算费用；群里只显示本群，各群明细只在私聊里列 |
| `/AI群友 重置用量` | BOT 管理员 | 本群或本私聊今天的额度从现在重新算，用量统计不变 |
| `/AI群友 上下文` | 群里需群管理员 | 下次请求占上下文的比例，人设规则、群信息、表情包目录、备忘、原文、末尾提示、看过的图各占多少 token（按上次实际输入折算的约数），缓存命中率、今日额度和精力；额度用完时会写明 |
| `/AI群友 记忆` | 群里需群管理员 | 她对本群和最近说过话的人的印象 |
| `/AI群友 记忆 删 QQ号` | BOT 管理员 | 删掉她对某人的印象（所有群共用） |
| `/AI群友 忘记我` | 所有人 | 删掉她对自己的印象 |
| `/AI群友 只回艾特 [开\|关]` | 群里需群管理员 | 本群是否只在被 @ 时回复；不带参数时查看当前状态 |
| `/AI群友 表情` | 群里需群管理员 | 列出收藏的表情包和使用次数 |
| `/AI群友 表情 看 名字` | 群里需群管理员 | 发出这张收藏的表情包 |
| `/AI群友 表情 删 名字` | BOT 管理员 | 删掉一张收藏（所有群共用），以后再看到同一张也不收 |
| `/AI群友 人设` | 群里需群管理员 | 当前人设和可选的预置人设 |
| `/AI群友 人设 看 [名字]` | 群里需群管理员 | 当前或某个预置人设的全文 |
| `/AI群友 人设 换 名字` | BOT 管理员 | 换成预置人设（大肥鱼、小埋），`默认` 回到配置里的；所有群生效 |
| `/AI群友 人设 改 名字 人设内容` | BOT 管理员 | 换成自定义人设，名字也算唤醒词；所有群生效 |


## 安装

在 WebUI 的插件市场安装，或由 Master 在聊天里 `/安装插件 persona_chat`。装好后默认不启用，`/启用插件 persona_chat` 即可加载。

## 配置

`config/tenko.toml` 的 `[plugin_config.persona_chat]`，也可以在 WebUI 的插件配置里修改。`api_key` 必填，只写在本机配置里，不要提交到任何仓库：

```toml
[plugin_config.persona_chat]
api_key = "sk-..."
```

在 WebUI 里保存时，除 `base_url`、`api_key`、`sticker_limit` 以外的项就地生效，不重载插件；改这三项会重载插件。直接改配置文件要重启才生效。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `base_url` | `"https://api.deepseek.com"` | OpenAI 兼容接口地址 |
| `api_key` | `""` | 接口密钥，为空时不应答 |
| `model` | `"deepseek-flash"` | 模型名 |
| `reasoning_effort` | `"high"` | 聊天回复的思考强度：`low`、`high`、`max`，留空不思考（DeepSeek 把 `medium` 当 `high`） |
| `wake_words` | `[]` | 除了当前人设的名字，消息含这些词时也当作在叫 bot |
| `persona` | `""` | 人设提示词，为空时用内置“大肥鱼”；只写人物本身，怎么当群友是通用规则。用 `/AI群友 人设` 换的预置或自定义人设优先 |
| `catchphrases` | `[]` | 人设里的梗和口头禅，她最近用过的会被点名让她别再用；为空且用内置人设时用内置的 |
| `context_tokens` | `32000` | 请求输入超过这么多 token 后把较早的聊天压成备忘，压回一半左右 |
| `batch_size` | `8` | 没在聊天时累计多少条新消息后考虑插话，`0` 关闭 |
| `follow_seconds` | `180` | bot 说话后多久之内每条新消息都考虑接话，`0` 关闭 |
| `quiet_seconds` | `3` | 主动说话前等群里安静多久 |
| `typing_seconds` | `20` | 她想好之前叫她、跟她聊的人又说了，就合起来重想，从开始想起最多这样等多久；`0` 叫到就回、不重想 |
| `unprompted_interval_seconds` | `300` | 没在聊天时两次插话的最短间隔 |
| `user_cooldown_seconds` | `5` | 同一个人叫 bot 的最短间隔 |
| `stamina` | `15` | 精力：10 分钟内说多少句算累（1 小时按两倍），`0` 不限 |
| `vision_images` | `5` | 每次请求最多带几张新图给模型看，`0` 只用 `[图片]` 文字 |
| `search_daily` | `20` | 每个群或私聊每天最多上网搜几次，`0` 关闭搜索 |
| `search_provider` | `"deepseek"` | 搜索服务：`deepseek`、`tavily`、`bocha`、`searxng` |
| `search_api_key` | `""` | 搜索服务的密钥；`deepseek` 留空用 `api_key`，`searxng` 不用 |
| `search_base_url` | `""` | 搜索服务的地址，留空用各家默认（`deepseek` 跟 `base_url`）；`searxng` 必填 |
| `sticker_limit` | `100` | 表情包收藏上限，所有群共用，`0` 关闭表情包 |
| `max_reply_chars` | `120` | 单条回复字数上限，超出时在句末截断 |
| `group_daily_tokens` | `200000` | 每个群每天的 token 上限（未命中缓存的输入加输出），用完后当天不再理这个群的消息、也不记录，`0` 不限 |
| `banned_words` | `[]` | 违禁词，含这些词的群友消息她看不到，含这些词的回复不发；不分简繁、全半角和大小写，忽略空格和标点，拼音 8 个字母以上的还按读音比 |
| `global_daily_tokens` | `0` | 全部会话合计每天的 token 上限，`0` 不限 |

搜索服务：

| `search_provider` | 密钥 | 价格 | 说明 |
| --- | --- | --- | --- |
| `deepseek`（默认） | 留空就用 `api_key` | 每次约 0.005 元，搜不到不收费 | DeepSeek 开放平台的 `/v1/tools/search`，地址跟 `base_url` |
| `tavily` | [Tavily](https://tavily.com) 的 `tvly-...` | 每月免费 1000 次，之后每次 0.008 美元 | basic 深度，英文和外网内容好 |
| `bocha` | [博查](https://open.bochaai.com) 的密钥 | 每次 0.036 元，预付费 | 国内网页收得全，带长摘要 |
| `searxng` | 不用 | 免费 | 自建的 SearXNG，`search_base_url` 填实例地址，`settings.yml` 的 `search.formats` 里要开 `json` |

打开网页时，`tavily` 用它自己的 `/extract`，只挑和要找的内容相关的几段（每 5 页 1 credit，打不开不收）；其他服务用不要 key 的 [Jina Reader](https://jina.ai/reader)。搜索设置在搜的时候才读，WebUI 里改了不用重载；配置用不了（服务名写错、缺密钥、SearXNG 没填地址）时记一条警告，她这时不搜，直接回话。

`/AI群友 用量` 的费用：上游在用量里报了实际扣费（比如 OpenRouter 的 `cost`）就照记，否则按 `deepseek-flash` 官方价目估算（工作日 UTC 01–04、06–10 点为高峰价）；搜索按上表价格估算，不扣 Tavily 的免费额度。DeepSeek 官方接口和 OpenRouter 的思考内容、缓存命中字段都认得，每日额度两种接口都算得对。
