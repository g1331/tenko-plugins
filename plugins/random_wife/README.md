# tenko-plugin-random-wife

[Tenko](https://github.com/g1331/tenko) 的随机老婆插件，移植自旧版 xiaomai-bot 的 `random_wife`。群友每天抽一个老婆，
抽到别人的老婆两次就能抢过来。

```text
群友 A：/抽老婆
Tenko： 你今天的老婆是芙莉莲哦~不想要了可以 /离婚 [图片]
群友 B：/抽老婆
Tenko： 你抽到了芙莉莲，是【群友 A】的老婆哦~ [图片]
群友 B：/抽老婆
Tenko： 你抢走了【群友 A】的老婆芙莉莲~ [图片] 达成成就【NTR】
```

## 命令

| 命令 | 谁能用 | 说明 |
| --- | --- | --- |
| `/抽老婆`（`/随机老婆`、`/随机wife`） | 所有人，仅群聊 | 抽一个今天的老婆；已经有了就再看一眼她 |
| `/离婚` | 所有人，仅群聊 | 放弃今天的老婆，之后可以重新抽 |
| `/添加老婆 <名字> [图片]`（`/添加wife`） | BOT 管理员直接添加；群员在群里发是投稿 | 图片可以和命令一起发，也可以引用一张图片发命令 |
| `/删除老婆 <名字>`（`/删除wife`） | BOT 管理员 | 按名字精确删除 |
| `/老婆列表 [关键词] [-p 页码]` | 所有人 | 老婆库的缩略图列表，带名字、文件大小和格式，每页 30 位；命令后面的文字都按名字搜，翻页用 `-p`，例如 `/老婆列表 02`、`/老婆列表 中野 -p 2` |

## 规则

- 每个群各自登记，每天零点清空；同一个老婆在不同的群可以有不同的主人。
- 没有老婆时抽到没人要的，她就是你的了；抽到别人的老婆只是看看。
- 在拿到老婆之前，最近 10 次抽到的别人的老婆里，有一个被抽到第二次，就把她抢过来，原来的主人可以重新抽。
- `/抽老婆` 计入限流的权重是 3。登记存在插件数据里，重启不会丢。

## 老婆库

老婆库是插件数据目录 `.tenko/plugin-data/random_wife/wives/` 下的图片，文件名（去掉后缀）就是名字，支持 jpg、png、gif、webp、bmp。

群员投稿时，图片和申请会发给审核的人，审核的人引用这条消息回复 `y` 同意，回复其他内容就作为理由拒绝，结果会 @ 投稿的人：

- 配置了审核群：发到审核群，群管理员都能审核；
- 没有配置：按 Tenko 的 Master 通知设置发给 Master（私聊或通知群），只有 Master 本人能审核。
  投稿太频繁时宿主会限速，投稿人会收到“过一会儿再来”。

申请 24 小时内有效。

插件在新群默认开启，群管理员可以用 `/关闭 随机老婆` 关掉。

### 从旧版 bot 导入

把旧版 bot 的 `modules/self_contained/random_wife/wife/` 里的图片拷进 `wives/`，`__init__.py` 不用拷。发图时按文件内容判断格式，
后缀和内容对不上（比如 jpg 存成了 `.png`）也没关系。有两种情况要手动处理：

- 后缀不在上面五种里的文件不会被认出，例如 mirai 缓存下来的 `.mirai`，按实际格式改个后缀；
- 同名不同后缀的文件（`凑阿库娅.jpg` 和 `凑阿库娅.gif`）只会认一个，给其中一个改名。

```text
cp /path/to/xiaomai-bot/modules/self_contained/random_wife/wife/* .tenko/plugin-data/random_wife/wives/
rm .tenko/plugin-data/random_wife/wives/__init__.py
```

导入后用 `/老婆列表` 核对数量，不用重启。

## 安装

在 WebUI 的插件市场安装，或由 Master 在聊天里 `/安装插件 random_wife`。装好后默认不启用，`/启用插件 random_wife` 即可加载。

## 配置

`config/tenko.toml` 的 `[plugin_config.random_wife]`，也可以在 WebUI 的插件配置里修改：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `review_group` | `""` | 群员投稿发到这个群审核；留空时发给 Master 审核 |
