# 战地六查询

经 [bf-manager](https://github.com/g1331/bf-manager) 的公开查询接口查询战地六玩家数据，回复图片；渲染不了时退回文字。图后面附上 bf-manager 网页的玩家页链接。

| 命令 | 说明 |
| --- | --- |
| `/bf6绑定 <EA 名字>`（也可以 `/bf6b`） | 绑定自己的 EA 账号；不带名字查看当前绑定 |
| `/bf6s [EA 名字]`（`/bf6战绩` `/bf6生涯`） | 生涯战绩：K/D、KPM、SPM、胜率、场次和时长，战斗表现，王牌装备，兵种和武器大类，生涯之最，常玩模式和地图，玩过的话还有禁区冲突（大逃杀） |
| `/bf6w [类别] [EA 名字]`（`/bf6武器`） | 武器排行，默认 2 列 5 行，可按类别筛选、`-n` 按名字搜、`-s` 换排序，见下 |
| `/bf6v [类别] [EA 名字]`（`/bf6载具`） | 载具排行，用法同上 |
| `/bf6r [EA 名字] [-n 条数]`（`/bf6对局` `/bf6最近`） | 对局估算，默认 8 条，`-n` 最多 20 条 |

战地六的命令都带 `bf6` 前缀；`/战绩`、`/武器` 这些不带前缀的命令仍然查战地一。

查玩家的命令都可以不带名字：绑定过就查绑定的号，没绑定时把群名片（去掉开头 `[战队]`、`【…】` 这类前缀）当 EA 名字查。名字要写 EA 账号的显示名，Steam 昵称和 EA 显示名不同时用 EA 的。都可以加 `-t`（`-text`）只回文字不出图。

战地六和战地一的绑定互不相通，两边各绑一次。

## 武器和载具排行

类别可以写在名字前面或后面（`/bf6w 卡宾枪 JackFrags`、`/bf6w JackFrags 卡宾枪`）：

- 武器：`突击步枪`（`突击`）、`卡宾枪`（`卡宾`）、`冲锋枪`（`PDW`）、`机枪`（`轻机枪`）、`狙击步枪`（`狙击` `栓狙`）、`精准射手步枪`（`射手步枪` `连狙` `DMR`）、`霰弹枪`（`散弹枪` `喷子`）、`手枪`（`配枪`），以及 `配备`（`装备`），列出火箭筒、C4、手雷这类配备的使用次数和战果
- 载具：`空中`（`飞机`）、`地面`（`陆地`）、`海上`（`船`）

选项：

- `-s`（`-sort` `-排序`）换排序。武器可以按 `击杀`（默认）、`KPM`、`命中率`、`爆头率`、`伤害`、`时长` 排；载具可以按 `击杀`、`KPM`、`伤害`、`时长`、`里程` 排；配备可以按 `使用`（默认）、`击杀`、`伤害`、`摧毁`、`修理` 排。按 KPM、命中率、爆头率排时，击杀不到 10 的不参与排名。
- `-n`（`-name` `-名字`）按名字搜，不分大小写，空格和 `-` 忽略（`-n m4` 能搜到 M4A1），没上榜的也置灰列在后面。
- `-c`（`-col` `-列`）、`-r`（`-row` `-行`）自己排几列几行，最多 6 列 10 行。

例如 `/bf6w 突击 JackFrags -s 爆头率 -c 3 -r 3`。

## 对局估算

EA 不提供战地六的逐场战报。bf-manager 会定时重读查过的玩家的生涯，两次读取之间场次或战斗时间涨了，就把差值记成一条。所以：

- 两次读取之间只打了一局时，能对上地图、模式和胜负；打了几局就合并成一条“N 场”，只列各模式的场次。
- 时间是读到变化的时刻，写成北京时间的区间。
- 有人查过这名玩家（`/bf6s`、`/bf6w`、`/bf6v`、`/bf6r` 都算，在 bf-manager 网页上打开也算）才开始记录，7 天没人查就停；记录保留 90 天。第一次查时还没有对局，之后打完的对局会陆续出现。

## 配置

```toml
[plugin_config.bf6]
base_url = "https://bfm.umrbotech.com"  # bf-manager 地址，不带 /api/v1
```

新群默认开启。
