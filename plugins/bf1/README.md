# 战地一查询

经 [bf-manager](https://github.com/g1331/bf-manager) 的公开查询接口查询战地一数据，回复图片；渲染不可用时退回文字。

| 命令 | 说明 |
| --- | --- |
| `/bf1绑定 <EA 名字>`（简写 `/bf1b`） | 绑定自己的 EA 账号；不带名字查看当前绑定 |
| `/bf1s [EA 名字]` | 生涯战绩；绑定后可不带名字 |
| `/bf1w [EA 名字]` | 武器击杀前十 |
| `/bf1v [EA 名字]` | 载具击杀前十 |
| `/bf1ss <服务器名关键字>` | 搜索有人的私服，显示前十个 |
| `/bf1pl <服务器名关键字 \| gameId>` | 服务器玩家列表（含排队、观战和行动进度）；匹配多个时取人最多的 |
| `/bf1` | 全服在线概况 |
| `/bf1审核 [开\|关]` | 本群的入群审核；开关需要群管理员 |

新群默认开启。

## 入群审核

在群里 `/bf1审核 开` 后，有人申请入群时 bot 会查申请者填的 EA 名字，把检查结果（没玩过战地一、BFEAC / BFBAN
实锤、和这个 QQ 已绑定的号不一致）和战绩卡片发到群里。群管理员**回复这条消息** `y` 同意，回复其他文字则以该文字为理由拒绝，不限时；同意后，申请者还没绑定的话自动绑定为这个 EA 名字。

需要 bot 是群管理员：QQ 只把入群申请推给群主和管理员。群里有多个 bot 号、选路选中的又不是管理员时，Tenko 4.0.0rc49 之前会把申请丢掉，之后由收到申请的管理员号处理。入群方式设成“需要回答问题并由管理员审核”，问题让申请者填 EA 名字。待审申请存在插件数据库里，重启 Tenko 后照样能回复处理；要用收到申请的那个 bot 号处理，它不在线时会提示等它上线。申请在 QQ 里直接处理掉、申请者进群后，记录自动清掉。

## 配置

```toml
[plugin_config.bf1]
base_url = "https://bfm.umrbotech.com"  # bf-manager 地址，不带 /api/v1
```
